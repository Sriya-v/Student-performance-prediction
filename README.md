# Student Performance Prediction using Machine Learning

A Machine Learning based project that predicts student academic performance based on study hours, attendance percentage, and previous scores.

## Objective

The main objective of this project is to predict whether a student is likely to pass or fail using machine learning techniques.

## Features

- Predicts student performance using input parameters
- Uses Machine Learning classification algorithm
- Calculates model accuracy
- Provides instant prediction results

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Machine Learning

## Machine Learning Algorithm

- Logistic Regression

## Input Parameters

The system takes:

- Hours Studied
- Attendance Percentage
- Previous Score

## Working

1. Student dataset is loaded.
2. Data is preprocessed.
3. Machine learning model is trained.
4. User details are provided as input.
5. Model predicts student performance.

## Output

The system predicts whether the student is likely to PASS or FAIL.

## How to Run

1. Install required libraries:

pip install -r requirements.txt

2. Run the program:

python student_prediction.py

## Project Purpose

This project demonstrates the application of machine learning for academic performance prediction and decision support.
